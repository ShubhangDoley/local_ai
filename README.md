# Local AI Chat Ecosystem

A privacy-focused, hybrid AI chat application combining **on-device local inference (offline)** and a **FastAPI + Ollama proxy server (online)**. Built with Flutter for cross-platform mobile support and Python for the backend proxy.

---

## 🏗️ Architecture Overview

The system operates in two distinct modes:

```mermaid
graph TD
    subgraph Mobile App (Flutter Frontend)
        UI[Chat Interface]
        MM[Model Manager]
        PM[Provider State]
    end

    subgraph Offline Mode (On-Device)
        Engine[LiteRT-LM Engine]
        Models[(Local .task/.litertlm Files)]
    end

    subgraph Online Mode (Remote Backend)
        API[FastAPI Server]
        Ollama[Ollama Instance]
    end

    UI --> PM
    PM -->|Local Mode ON| Engine
    Engine -->|Reads weights| Models
    PM -->|Local Mode OFF| API
    API -->|Proxies prompt| Ollama
```

## 📱 Flutter Frontend (`flutter frontend/local_ai`)

An offline-first chat client supporting multi-model downloads and local inference.

### Key Features
* **Hybrid Mode Toggle**: Switch between Online (Backend API) and Offline (On-device LLM) modes dynamically in the settings.
* **On-Device Inference**: Uses Google's **LiteRT-LM** (formerly MediaPipe LLM Inference) engine to execute quantized model instructions directly on the phone's CPU/GPU.
* **Model Manager UI**: A glassmorphic modal sheet listing specialized models:
  * **Gemma 2B IT (General)**: Optimized for general queries and conversations.
  * **DeepSeek R1 1.5B (Reasoning/Code)**: Optimized for logical reasoning and programming questions.
  * **Qwen 2.5 1.5B (Multilingual)**: Strong performance across multiple languages.
  * **Phi 3 Mini (Logic/Math)**: Specialized in logic and analytical reasoning.
* **Download & Storage Manager**: Downloads models with real-time percentage indicators and allows deleting downloaded files to free up storage space.

### Setup & Run
1. Ensure **Developer Mode** is enabled on Windows (Settings > Update & Security > For Developers > Enable Developer Mode). This is required to support symlinks generated by Flutter plugins.
2. Navigate to the frontend directory:
   ```bash
   cd "flutter frontend/local_ai"
   ```
3. Fetch packages:
   ```bash
   flutter pub get
   ```
4. Run the application:
   ```bash
   flutter run
   ```

## 🐍 FastAPI Backend (`fastapi backend`)

A lightweight Python FastAPI proxy wrapper serving as the gateway to your desktop's local Ollama service.

### Key Features
* Exposes a `/chat` POST endpoint receiving user prompts.
* Connects to a local Ollama instance (`http://localhost:11434`) running the `gemma:2b` model.
* Serves as a gateway for external mobile clients over the local network.

### Setup & Run

#### Prerequisites
* Install [Ollama](https://ollama.com/) and download the gemma model:
  ```bash
  ollama run gemma:2b
  ```

#### Virtual Environment & Installation
It is recommended to run this in a Conda environment to avoid path issues:
1. Create a Conda environment:
   ```bash
   conda create -n local_ai_dev python=3.10 -y
   ```
2. Activate the environment:
   ```bash
   conda activate local_ai_dev
   ```
3. Install dependencies:
   ```bash
   pip install fastapi uvicorn requests
   ```
4. Start the server:
   ```bash
   uvicorn main:app --host 0.0.0.0 --port 8000 --reload
   ```

> [!NOTE]
> Make sure to update the `backendHost` IP in `flutter frontend/local_ai/lib/providers/chat_provider.dart` to match your desktop machine's local IP address so your physical mobile phone can reach it.

## 🛠️ Troubleshooting

### Windows Symlink Error (`flutter pub get` fails)
If `flutter pub get` fails with exit code 1 mentioning "symlink support", you must enable **Developer Mode** on Windows. Run:
```powershell
Start-Process ms-settings:developers
```
Turn on "Developer Mode" and restart your IDE or console.

### Virtual Environment Launcher Errors (`Fatal error in launcher`)
If you move your project folder to another directory or drive, Python's absolute paths in `venv/Scripts` break. Switch to a Conda environment or recreate the venv on the new path:
```powershell
deactivate
Remove-Item -Recurse -Force venv
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install fastapi uvicorn requests
```
